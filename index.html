Chaque cours est noté selon sa qualité de transcription : A complet (ou quasi-complet) & relu · B incomplet ou non relu · C premier jet — à utiliser avec prudence.

Si vous repérez des erreurs et des preuves manquantes, ou que vous voulez ajouter vos propres transcriptions, les contributions des prochaines promotions sont les bienvenues via Pull Request sur GitHub ↗. Vous pouvez aussi forker ce répertoire et y travailler individuellement.
